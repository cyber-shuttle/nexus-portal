## Saved views feature summary

**Module:** `src/features/analytics/views/` (peer of `components/`, intra-feature).

- `types.ts` — `SavedView`, `CreateSavedViewPayload`, `UpdateSavedViewPayload`, `SAVED_VIEW_LIMIT_PER_PERSONA = 5`.
- `schemas.ts` — Zod schemas for the wire shapes (list / create / update / view), incl. a `.refine` on the update payload that requires at least one mutable field.
- `api.ts` — `getSavedViews`, `createSavedView`, `updateSavedView`, `deleteSavedView` — all forward `?user=` for the MSW dev convention.
- `queries.ts` — `useSavedViews`, `useCreateSavedView`, `useUpdateSavedView`, `useDeleteSavedView`. Query key includes both persona and userId so an account / persona switch invalidates cleanly.
- `components/SavedViewChips.tsx` — renders up to 5 chips in a `<fieldset role="group">`; each chip is a button + trailing `…` kebab (DropdownMenu) with Set-default and Delete actions.
- `components/SaveViewPopover.tsx` — Base-UI popover triggered by `[data-testid="analytics-save-view-trigger"]`. Captures `name` (1–80 chars, trimmed) + `is_default` checkbox; surfaces the 5-per-persona cap inline and propagates server errors (`name_conflict`, `limit_reached`) into the form.
- `components/SavedViewsToolbar.tsx` — composes the chips + popover into two slot nodes a container can drop into its MetaRow. Owns the apply-to-URL write so range + group_by land in a **single** `router.replace` (otherwise the second writer clobbers the first — fixed in `6b8673e`).

**MSW handlers + seed:** `src/mocks/handlers/analytics-views.ts` (`GET/POST/PUT/DELETE /api/v1/analytics/views`). Validates payloads with the views feature's Zod schemas; enforces the 5-per-(user, persona) cap with `409 limit_reached`; enforces name uniqueness with `409 name_conflict`; clears the default flag on a user's other views in the same persona when `is_default: true` is set. Caller id read from `x-nexus-user` header / `?user=` query, defaulting to researcher persona (same convention as `users.ts`).

Seed (`src/mocks/seed/index.ts`) ships two views per dev persona (one `is_default: true`, one secondary) so the chip strip is non-empty on first load.

**Persona wiring:** `Researcher` (`?gb=resource,project`), `PI` (`?gb=project,member,resource`), and `Admin` (`?gb=resource,project,org`) containers all hand the toolbar slots through to their feature components via two new optional props (`savedViewsChips`, `saveViewTrigger`). The disabled `+ Save view` placeholder is gone in all three.

**Default-on-load:** `useSavedViewsToolbar` auto-applies the `is_default` view exactly once per mount when none of `preset`, `from`, `to`, `gb` are present in the URL. Subsequent URL state changes take precedence within the session.

**Atomic apply:** `applyRangeToParams` + `applyGroupByToParams` helpers compose both keys into one `URLSearchParams` so the chip click issues one `router.replace`. Bug discovered in e2e: independent `setRange` + `setGroupBy` calls each read the same `searchParams` snapshot and the second write clobbered the first.

**Persistence:** `persistSeed()` is called inside POST / PUT / DELETE handlers so a full-page reload re-hydrates the chip strip from `localStorage` (goal-1 Phase 6 contract). Verified by the e2e reload assertion.

- **A2 N6 — Avg burn /project label says `/mo` but value is window total.** A6 polish.
- **A2 N7 — Member-bar Y-axis renders raw `user_id`.** A6 polish.
- **A2 N2 — Multi-chip URL contract is page-local.** Slot meaning still differs per persona; the saved-view payload captures the literal slot array so cross-persona apply isn't safe (a researcher view can't be applied to admin even if the user has both personas). A6 should add a `version` field + slot-name mapping.
- **Saved-view range snapshot is fixed at save time.** A `preset: "7d"` view re-applies the literal window at save time, not "last 7 days from now". An "update view to current URL state" affordance is a v2 follow-up; documented in the contract doc.
- **DropdownMenu trigger doesn't have a long-press affordance on touch.** The spec text mentions "long-press (or context menu, or trailing `…` button)"; we shipped the trailing kebab as the discoverable option. Long-press would be additive.
- **Toast wording** is in English-only and uses curly quotes — confirm with i18n / localization work in v2.
