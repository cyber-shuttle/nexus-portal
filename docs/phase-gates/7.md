## Phase 7 new features

### 1. General admin module (`558f8e9`)

`src/features/admin/` extended with `components/`, full schemas for resources / rates / unmapped-jobs / adjustments / allocation-summary, new API + query hooks. MSW handlers (`src/mocks/handlers/admin.ts`) implement all endpoints with `persistSeed()` on every mutation. Seed gains `unmappedJobs[]` (18 rows), `adjustments[]` (12 rows), and `preferences{}` (empty). Backend contract docs at `docs/backend-contracts/admin.md` and `docs/backend-contracts/unmapped-jobs.md`.

Routes:

- `/admin/resources` — site-wide resource rollup table with cluster/status/search filters, click-through to a side drawer that renders a 30-day stacked-area usage trend (Recharts).
- `/admin/rates` — versioned SU/unit rates per resource with effective windows, create form, and supersede (sets `effective_to = now`).
- `/admin/unmapped-jobs` — SLURM accounting orphans. Inline expand per row for link-to-allocation (select picker) + discard-with-reason.
- `/admin/adjustments` — CRUD over manual SU credits / debits / expirations. Type filter, create form, reason ≥ 3 chars.

Sidebar (`shared/layout/navConfig.ts`) adds Resources / Rates / Unmapped Jobs / Adjustments entries, each gated by `ability: { action: "manage", subject: <Subject> }` so only admins see them (admin's `manage all` covers them; future role-restricted ops viewers can be added with one ability rule).

### 2. Settings page (`56589bb`)

New `features/auth/` module: `schemas.ts`, `api.ts`, `queries.ts`, `components/SettingsPage.tsx`. Sections:

- **Profile** — name (session) / email (read-only) / connected identities (from `GET /me/identities`).
- **Preferences** — theme (light/dark/system via `next-themes`; ThemeProvider wired in `shared/providers/Providers.tsx`, `.dark` token overrides added to `design-tokens/colors.css`), timezone picker (6 zones), and two notification checkboxes. `Save settings` → `PUT /me/preferences` (validated by `updatePreferencesPayloadSchema`).

MSW handlers in `src/mocks/handlers/users.ts` route off an `x-nexus-user` header / `?user=` query so the dev-mode persona has stable preferences; documented in `docs/backend-contracts/auth.md`.

### 3. Error pages + loading states (`a59a0c0`)

- `src/app/not-found.tsx` — Nexus-branded 404 with link back to `/home`.
- `src/app/error.tsx` — client-side error boundary that renders `ErrorState` with a reset button and an optional digest reference.
- `src/app/(portal)/loading.tsx` — global portal loading state (`CenteredSpinner`).

- Skip-to-main link in `shared/layout/PortalLayout.tsx`: focusable, hidden until focus, target is `<main id="main-content" tabIndex={-1}>`.
