## HIGH findings + resolutions

### H1 — Page heading typography drift from §5.3 / §13 (Recurring across 20 pages)

**Rule:** Spec §5.3 mandates `Page title h1 — Manrope, 28px, weight 700, leading 1.2`. Reflected in §13 conformance: `Typography — h1 28px bold`.

**Before:**
- 12 files used `font-heading text-2xl font-semibold` (24px / 600 weight)
- 5 files used `font-display text-2xl font-bold tracking-tight` (24px / 700 / `-0.025em`)
- 3 dashboard files used `font-heading text-3xl font-semibold` (30px / 600)
- `AllocationsList.tsx` used `font-heading text-3xl font-semibold` (30px / 600)

**After:** All 21 page-title h1s standardized to `font-display text-[28px] font-bold leading-tight`.
