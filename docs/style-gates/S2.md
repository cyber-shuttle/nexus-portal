3. **StatCard `trend` prop** — kept as deprecated to preserve `AdminDashboard.tsx:125` etc. without churn. S5 page sweep will remove all `trend` callers and we can drop the prop.
4. **PlaceholderPage hardcoded blue utilities** — explicitly deferred to S4 sweep.
5. **Button size scale change ripple** — h-9 default vs the old h-8 will visibly grow buttons in ~all feature pages. Intentional per spec §7.5; QA will verify against Figma during S3.
6. **NavArrows direction detection** — `useNavHistory` reconciles cursor against the known stack on `popstate`, but if browser history has been mutated (deep-link refresh, external nav) the heuristic resets. Acceptable — disabled state is conservative ("if unsure, both available") and never breaks navigation.
