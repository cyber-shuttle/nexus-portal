## Primitives shipped (spec §7)

- **`KpiCard`** (`src/shared/ui/KpiCard.tsx`) — `title + value + delta? + sparkline?`; wraps in a `<button>` when `onClick` is passed; skeleton variant for `loading=true`. Delta tone is explicit so callers control "up = good" semantics.
- **`DateRangePicker`** (`src/shared/ui/DateRangePicker.tsx`) — Base UI Popover; preset chips (24h/7d/30d/90d) plus a Custom… reveal with two `<input type="date">`s and an Apply button gated on `from <= to`.
- **`GroupByChip`** + **`GroupByChipGroup`** (`src/shared/ui/GroupByChip.tsx`) — Base UI Menu trigger styled as `Button variant="outline" size="sm"`; current value marked with a checkmark; chip group lays children out with `gap-2`.
- **`LastSyncedBadge`** (`src/shared/ui/LastSyncedBadge.tsx`) — Pill renders `Synced 12 min ago` via shared `formatRelative`; green <1h, amber 1h-24h, red >24h; optional refresh icon button.
- **`ForecastBar`** (`src/shared/charts/ForecastBar.tsx`) — Wraps `BurnDownBar`; adds a vertical marker line at `(projected/capacity)%` and a caption `Projected exhaust {date} — N days {before|after} award end`. Red when exhaust < endDate; muted otherwise.
- **`ComplianceMatrix`** (`src/shared/charts/ComplianceMatrix.tsx`) — Generic `<R, C>` heatmap with sticky-left row labels via `position: sticky; left: 0`; cell bands use token-arbitrary colors (`bg-[color:var(--nexus-green-100)]`, amber, red, `bg-muted`); per-cell `aria-label` includes row+col context; clickable cells call `onCellClick(r, c)`.
- **`DrillStack`** (`src/shared/ui/DrillStack.tsx`) — Wraps `SideDrawer`; crumb row rendered above the title using ghost-variant buttons joined by ChevronRight separators.

## Aggregator extension (`src/shared/api/aggregator.ts`)

- **`pace(allocation, usages, now)`** — compares `used/allocated` to `elapsed/period_total`; ±10% tolerance returns `on-pace`, otherwise `over`/`under`.
- **`forecast(usages, allocation, asOf)`** — rolling-7d slope; requires 7 distinct days in window; returns `{ exhaustDate, daysRemaining, method: "rolling-7d" }` or nulls.
- **`topN(items, by, n, otherLabel, reducer?, makeOther?)`** — top-N by score with optional aggregated "Other" via `reducer` or `makeOther`.
- **`complianceMatrix(rows, cols, scoreFn)`** + **`bandForUsageRatio(ratio)`** — produces `ComplianceCell[][]` for the matrix renderer; bands match `UsageBar` thresholds (≥90% hot, ≥75% warn, ≥1% ok, else empty).

Existing `home` consumers updated to import from `@shared/api/aggregator` (commit `2b9b536`).

## URL hooks + persona resolver

- **`useUrlRange`** (`src/shared/hooks/useUrlRange.ts`) — `?preset=&from=&to=` <-> `{ from, to, preset }`; `custom` requires both ISO strings with `from <= to`; defaults to last 30 days.
- **`useUrlGroupBy`** (`src/shared/hooks/useUrlGroupBy.ts`) — `?gb=a,b,c` <-> `string[]`; empty clears the param.
- **`personaForAnalytics`** (`src/shared/auth/personaForAnalytics.ts`) — first-match wins: `admin`/`allocation_manager` → `admin`, any PI membership → `pi`, else `researcher`.
- **CASL extensions** (`src/shared/casl/abilities.ts`) — `read Analytics` ability with three subjects `AnalyticsResearcher`/`AnalyticsPI`/`AnalyticsAdmin` and the rule set from spec §5.5.

## Open items / deferrals

- **`ComplianceMatrix` token-arbitrary tints are intentional.** None of the semantic tokens (`--brand`, `--destructive`, etc.) carry a four-band heatmap ramp; we use `bg-[color:var(--nexus-green-100)]` / amber / red / `bg-muted`. Spec §7.6 explicitly approves this; brand-utility grep stays zero because the syntax is `bg-[color:var(...)]`, not `bg-nexus-green-100`. If A3 widens the ramp we should revisit whether to add semantic `--matrix-band-*` aliases.
- **Pre-existing `@features/` self-import** at `src/features/allocations/components/AllocationDetailHeader.tsx:6` is a same-feature reference (alloc → alloc) carried over from S3 and called out there as acceptable. Not in A0 scope to refactor.
- **`KpiCard` `deltaTone` defaulting** — falls back to `neutral` if omitted. Phases A1–A3 must pass an explicit tone for every delta; visual QA at A1 gate should reject any "neutral by accident" cards.
- **`DrillStack` width default** — set to `lg` (max-w-2xl) since drill content is typically a table; widening if A2 PI member drill needs more space is cheap.
- **`forecast()` returns nulls below 7 distinct days.** Researcher A1 page needs to render a "Not enough data for a 7-day forecast" empty state on the ForecastBar caption when the result is `{ exhaustDate: null }`. Documented as an A1 implementation detail, not an A0 gap.
